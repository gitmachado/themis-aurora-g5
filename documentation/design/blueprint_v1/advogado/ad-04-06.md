# Tela: AD-04 - Gestão de Processos (Advogado)

- **Tipo**: [Tab Bar] Aba 3
- **Objetivo**: Filtro e busca global de todos os processos ativos no escritório.

## 🏗️ Anatomia Visual
1.  **Barra de Pesquisa**: Por nome do cliente, CPF ou ID do Processo.
2.  **Filtros de Nicho**: Chips persistentes (Trabalhista, Cível, etc).
3.  **Lista de Resultados**:
    - Nome do Cliente.
    - Status (`EM_ANALISE`, `AGUARDANDO_AUDIENCIA`, etc).
    - Última Movimentação.
4.  **Ação Flutuante**: Botão "+" para `AD-06 (Novo Processo)`.

## 📊 Mapeamento de Dados (G5-8)
| Componente | Fonte do Modelo | Descrição |
| :--- | :--- | :--- |
| Lista Processos | `Processo[]` | Paginado e ordenado por atualização. |
| Tags | `Processo.tipoCaso` | Ícones coloridos por categoria. |

## 🕹️ Interações e Regras
- **Clique no Item**: Navega para `AD-05 (Detalhe Processo)`.
- **Filtro de Status**: Dropdown com multi-seleção.

## 🎨 Dicas de Design
- Usar ícones distintos para cada tipo de caso jurídico.
- Barra de scroll lateral para filtros rápidos se forem muitos.

# Tela: AD-05 - Detalhe do Processo (Visão Admin)

- **Tipo**: [Stack] Gestão de Caso
- **Objetivo**: Atualizar o status e a timeline do processo para o cliente.

## 🏗️ Anatomia Visual
1.  **Header**: Resumo do cliente e dados do processo.
2.  **Editor de Timeline**: Botão "Adicionar Movimentação".
3.  **Seção de Documentos**: Grid de arquivos anexados com opção de "Solicitar correção".
4.  **Seção Administrativa**: Campo para mudar o `status` global do processo.

## 📊 Mapeamento de Dados (G5-8)
| Componente | Fonte do Modelo | Descrição |
| :--- | :--- | :--- |
| Timeline | `TimelineEvento[]` | Opção de editar/remover eventos. |
| Status Dropdown | `ProcessoStatus` | Enum de estados jurídicos. |

## 🕹️ Interações e Regras
- **Adicionar Nota**: Abre modal com editor Markdown.
- **Push Auto**: Ao salvar, o backend deve disparar FCM automaticamente.

## 🎨 Dicas de Design
- Layout de painel de controle (dashboard lateral) se houver espaço em tablet, ou lista vertical no mobile.

# Tela: AD-06 - Cadastro de Novo Processo (Advogado)

- **Tipo**: [Stack] Formulário
- **Objetivo**: Criar manualmente um processo que não veio de um Lead de WhatsApp.

## 🏗️ Anatomia Visual
1.  **Seleção de Cliente**: Autocomplete buscando no `User.nome`.
2.  **Dados do Caso**:
    - Título.
    - Número Unificado.
    - Tipo de Caso (Dropdown).
3.  **Upload Inicial**: Área para anexar a petição inicial ou documentos base.

## 📊 Mapeamento de Dados (G5-8)
| Componente | Fonte do Modelo | Descrição |
| :--- | :--- | :--- |
| Form Fields | `Processo` | Mapear para campos obrigatórios da entidade. |
| Cliente | `User` | Somente usuários com role `CLIENTE`. |

## 🕹️ Interações e Regras
- **Gerar Senha**: Opção de re-notificar o cliente se ele for novo.
- **Validação**: Verificar unicidade do número do processo.

## 🎨 Dicas de Design
- Divisão por cards/seções para não sobrecarregar o formulário.
