# Tela: AD-01 - Dashboard Operacional (Advogado)

- **Tipo**: [Tab Bar] Aba 1
- **Objetivo**: Visão 360 e métricas rápidas de produtividade do escritório.

## 🏗️ Anatomia Visual
1.  **Metric Cards (Mosaico)**:
    - Leads Pendentes (Count).
    - Casos em Draft (Count).
    - Handoffs ativos (Count).
2.  **Gráfico de Pizza**: Distribuição por nicho (Trabalhista, Cível, etc).
3.  **Feed de Documentos**: Lista horizontal com os últimos 5 arquivos recebidos dos clientes.

## 📊 Mapeamento de Dados (G5-8)
| Componente | Fonte do Modelo | Descrição |
| :--- | :--- | :--- |
| Contador Leads | `Lead.count(PENDENTE)` | Filtro por status. |
| Distribuição | `Processo.groupBy(tipoCaso)` | Agregação por enum. |
| Feed Docs | `Documento.limit(5).order(createdAt)` | Relacionamento global. |

## 🕹️ Interações e Regras
- **Clique no Gráfico**: Navega para a lista de Processos com o filtro de nicho aplicado.
- **Clique no Doc**: Navega para `AD-08 (Revisão de Documentos)`.

## 🎨 Dicas de Design
- Usar cores vibrantes para o gráfico (escala cromática).
- Cards com shadow suave para profundidade.

# Tela: AD-02 - Triagem de Leads (Advogado)

- **Tipo**: [Tab Bar] Aba 2
- **Objetivo**: Gestão da fila de novos contatos capturados pelo Bot do WhatsApp.

## 🏗️ Anatomia Visual
1.  **Lista de Cards de Lead**:
    - Nome do Lead e Tipo de Caso.
    - Tag de Urgência (Alta, Média, Baixa).
    - Resumo da IA (3 linhas).
    - Tempo de Espera.
2.  **Filtros**: botão para ordenar por tempo ou urgência.

## 📊 Mapeamento de Dados (G5-8)
| Componente | Fonte do Modelo | Descrição |
| :--- | :--- | :--- |
| Lista | `Lead[]` | Filtrar onde `status == PENDENTE`. |
| Tag Urgência | `Lead.urgencia` | `ALTA` -> Fundo Vermelho, `BAIXA` -> Fundo Cinza. |
| Resumo | `Lead.descricao` | Texto enriquecido pela triagem da IA. |

## 🕹️ Interações e Regras
- **Clique no Lead**: Navega para `AD-03 (Detalhe/Conversão)`.
- **Swipe Right**: Marcar como "Em atendimento".

## 🎨 Dicas de Design
- Usar etiquetas (badges) arredondadas para nichos.
- Exibir tempo de espera em formato relativo ("Há 12 min").

# Tela: AD-03 - Detalhe e Conversão de Lead (Advogado)

- **Tipo**: [Stack] Fluxo de Cadastro
- **Objetivo**: Validar informações capturadas pela IA e converter o Lead em Cliente.

## 🏗️ Anatomia Visual
1.  **Sessão de Dados Capturados**: Campos editáveis com Nome, CPF, Telefone e Contexto.
2.  **Transcrição IA**: Acordeão com a conversa completa tida no WhatsApp.
3.  **Ações**:
    - Botão "Converter em Cliente" (Criar Usuário).
    - Botão "Descartar Lead" (Spam/Fora de área).

## 📊 Mapeamento de Dados (G5-8)
| Componente | Fonte do Modelo | Descrição |
| :--- | :--- | :--- |
| Formulário | `Lead` | Dados originais para edição pré-conversão. |
| Transcrição | `Mensagem[]` | Histórico vinculado ao `phoneNumber` do Lead. |

## 🕹️ Interações e Regras
- **Conversão**: Aciona endpoint que cria `User` e `Processo` (Draft) em uma única transação.
- **Validação**: Impedir conversão sem CPF válido.

## 🎨 Dicas de Design
- Estilo "Stepper" se o processo de conversão tiver múltiplas etapas.
- Feedback visual forte após a conversão ("Cliente criado com sucesso!").
