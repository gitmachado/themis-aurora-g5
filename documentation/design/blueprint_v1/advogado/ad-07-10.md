# Tela: AD-07 - Diretório de Clientes (Advogado)

- **Tipo**: [Tab Bar] Aba 4
- **Objetivo**: Acesso rápido a todos os clientes cadastrados no escritório.

## 🏗️ Anatomia Visual
1.  **Lista de Usuários**:
    - Avatar/Iniciais.
    - Nome e CPF.
    - Quantidade de Processos Ativos.
2.  **Ação de Detalhe**: Ícone de chevron para ver histórico completo do cliente.

## 📊 Mapeamento de Dados (G5-8)
| Componente | Fonte do Modelo | Descrição |
| :--- | :--- | :--- |
| Lista | `User[]` | Filtrar por `role == CLIENTE`. |
| Stats | `Processo.count(userId)` | Contagem dinâmica por cliente. |

## 🕹️ Interações e Regras
- **Busca**: Campo de texto por nome ou e-mail.
- **Clique**: Abre visão consolidada do cliente (pode ser um modal ou nova stack).

# Tela: AD-08 - Revisão de Documentos (Advogado)

- **Tipo**: [Stack] Fluxo de Aprovação
- **Objetivo**: Validar arquivos enviados pelos clientes e anexar formalmente aos processos.

## 🏗️ Anatomia Visual
1.  **Fila de Revisão**: Lista de "Documentos Pendentes".
2.  **Visualizador**: Área central para visualizar o PDF/Imagem.
3.  **Botões de Ação**:
    - "Aprovar": Vincula permanentemente ao processo.
    - "Solicitar Novo": Abre chat/notificação pedindo para reenviar.

## 📊 Mapeamento de Dados (G5-8)
| Componente | Fonte do Modelo | Descrição |
| :--- | :--- | :--- |
| Lista de Revisão | `Documento[]` | Onde `status == ANALISE`. |

## 🎨 Dicas de Design
- Layout "Side-by-side" para visualização e botões de ação rápidos.

# Tela: AD-09 - Gestão IA & RAG (Advogado)

- **Tipo**: [Stack/Aba] Configurações
- **Objetivo**: Painel de controle para monitorar o comportamento do bot e atualizar base de conhecimento.

1.  **Status do Sistema**: Indicadores verdes/vermelhos para WhatsApp Cloud API e Modelos (Gemini/OpenAI).

| Componente | Fonte do Modelo | Descrição |
| :--- | :--- | :--- |
| Audit Log | `Mensagem.metadata.confidence` | Exibir score da IA se disponível. |

## 🎨 Dicas de Design
- Estilo "Admin Panel" focado em dados e status.

# Tela: AD-10 - Handoff (Chat Humano Ativo)

- **Tipo**: [Stack] Suporte Direto
- **Objetivo**: O advogado assume o controle e conversa diretamente com o cliente/lead.

## 🏗️ Anatomia Visual
1.  **Campo de Escrita**: Habilitado (diferente da visão do cliente).
2.  **Banner de Contexto**: "Você assumiu esta conversa. O bot está pausado."
3.  **Atalhos Rápidos**: Frases prontas ou seleção de arquivos.

## 📊 Mapeamento de Dados (G5-8)
| Componente | Fonte do Modelo | Descrição |
| :--- | :--- | :--- |
| Input | `Mensagem.save()` | Origem salva como `HUMANO`. |
| Status Chat | `Chat.handoffAtivo` | Flag para silenciar o bot via webhook. |

## 🕹️ Interações e Regras
- **Botão Encerrar**: Devolve o controle para a IA ou fecha o atendimento.
