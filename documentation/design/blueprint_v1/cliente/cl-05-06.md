# Tela: CL-05 - Timeline do Processo (Cliente)

- **Tipo**: [Stack] Detalhe de Processo
- **Objetivo**: Visualização atomizada e histórica de todos os passos de um caso específico.

## 🏗️ Anatomia Visual
1.  **Header**: Resumo do Processo (Título, Número e Advogado Responsável).
2.  **Linha do Tempo (Lista Vertical)**:
    - Nó (Ícone dinâmico: martelo, documento, check).
    - Título da Movimentação (ex: "Audiência Realizada").
    - Descrição/Nota explicativa (Markdown).
    - Data e Hora.
3.  **Botão de Ação**: "Tirar Dúvida" (Abre WhatsApp pré-preenchido com o contexto daquele evento).

## 📊 Mapeamento de Dados (G5-8)
| Componente | Fonte do Modelo | Descrição |
| :--- | :--- | :--- |
| Eventos | `TimelineEvento[]` | Relacionado ao `ProcessoId`. |
| Ícone do Nó | `TimelineEvento.tipo` | `AUDIENCIA` -> Ícone Martelo, `DOC_JUNTO` -> Ícone Doc. |
| Detalhe Markdown | `TimelineEvento.descricao` | Renderizar notas formatadas. |

## 🕹️ Interações e Regras
- **Scroll Infinito**: Se houver muitos eventos históricos.
- **Clique no Anexo**: Se o evento tiver um arquivo vinculado, navegar para visualização.

## 🎨 Dicas de Design
- Usar uma linha vertical tracejada para conectar os eventos.
- O evento mais recente deve estar no topo com brilho/glow sutil.

# Tela: CL-06 - Central de Notificações (Cliente)

- **Tipo**: [Stack] Global
- **Objetivo**: Fila de alertas push para que o cliente não perca nenhuma atualização.

## 🏗️ Anatomia Visual
1.  **Lista de Notificações**:
    - Ícone de Alerta.
    - Título e Subtítulo.
    - Timestamp (ex: "Há 5 min").
2.  **Ação de Limpar**: Ícone de lixeira no header.

## 📊 Mapeamento de Dados (G5-8)
| Componente | Fonte do Modelo | Descrição |
| :--- | :--- | :--- |
| Notificações | `Notificacao[]` | Filtrado por `userId`. |
| Status Leitura | `Notificacao.lida` | Diferenciar visualmente mensagens não lidas (background azul claro). |

## 🕹️ Interações e Regras
- **Clique no Card**: Navegação profunda (Deep Link) para a tela correspondente (ex: Timeline).
- **Marcar como Lida**: Ao clicar ou abrir a central.

## 🎨 Dicas de Design
- Layout limpo, estilo iOS Notification Center.
- Usar swipe-to-delete para cada notificação.
