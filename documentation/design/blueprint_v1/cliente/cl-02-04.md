# Tela: CL-02 - Lista de Processos (Cliente)

- **Tipo**: [Tab Bar] Aba 2
- **Atalho**: `@cliente-processos`

## 🧭 Navegação
- **Origem**: [CL-01: Home](cl-01-home.md)
- **Destinos possíveis**:
    - [CL-05: Timeline Detalhada](cl-05-timeline.md) (Ao selecionar um processo na lista)

## 🏗️ Anatomia Visual
- **Filtros**: Chip buttons para "Ativos", "Arquivados" e "Todos".
- **Lista Vertical**: Cards contendo:
    - Título/Apelido do caso.
    - Número Unificado (CNJ).
    - Badge de Status (ex: "Em Julgamento").
    - Data da última atualização.

## 📊 Mapeamento de Dados (G5-8)
- `Processo[]`: Coleção filtrada pelo `userId` logado.
- `Processo.status`: Define a cor e texto da badge lateral.

## 🕹️ Regras de Interface
- Implementar "Pull-to-refresh".
- Empty state com ilustração e texto: "Nenhum processo ativo encontrado".

# Tela: CL-03 - Central de Documentos (Cliente)

- **Tipo**: [Tab Bar] Aba 3
- **Atalho**: `@cliente-documentos`

## 🧭 Navegação
- **Destinos possíveis**:
    - Visualizador de PDF/Imagem (Nativo do OS).

## 🏗️ Anatomia Visual
- **Busca**: Campo de texto para filtrar arquivos por nome.
- **Categorias**: Tabs para "Meus Uploads" e "Recebidos do Advogado".
- **FAB (Floating Action Button)**: Ícone "+" para iniciar novo upload.

## 📊 Mapeamento de Dados (G5-8)
- `Documento[]`: Lista de arquivos vinculados ao usuário.
- `Documento.mimeType`: Define o ícone de arquivo (PDF, JPG, PNG).

## 🕹️ Regras de Interface
- Feedback visual de progresso (ProgressBar) durante o upload.
- Swipe to delete (apenas para arquivos pendentes de revisão).

# Tela: CL-04 - Chat / Suporte (Cliente)

- **Tipo**: [Tab Bar] Aba 4
- **Atalho**: `@cliente-chat`

## 🧭 Navegação
- **Contexto**: Espelho da conversa iniciada no WhatsApp.

## 🏗️ Anatomia Visual
- **Thread de Mensagens**: Bolhas de conversa com timestamp.
- **Status da IA**: Indicador "Assistente AI respondendo" ou "Advogado Assumiu".
- **Banner Informativo**: "Para enviar novas mensagens, use nosso WhatsApp oficial."

## 📊 Mapeamento de Dados (G5-8)
- `Mensagem[]`: Histórico sincronizado via webhook/socket.
- `Mensagem.origem`: Identifica se a bolha é verde (usuário) ou cinza (bot/advogado).

## 🕹️ Regras de Interface
- Campo de entrada de texto desativado (Read-only), a menos que o advogado tenha habilitado chat interno.
