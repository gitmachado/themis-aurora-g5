# Tela: CL-01 - Home/Dashboard (Cliente)

- **Tipo**: [Tab Bar] Aba 1
- **Objetivo**: Fornecer uma visão imediata do status jurídico e acesso rápido a suporte.

## 🏗️ Anatomia Visual
1.  **Header**: Saudação personalizada ("Olá, [Nome]") e atalho para Perfil/Configurações.
2.  **Status Card**: Card de destaque com o processo mais recente.
    - Indicador visual de progresso (Stepper).
    - Status atual em texto (ex: "Em análise pelo Juiz").
3.  **Ações Rápidas**:
    - Botão "Dúvida Urgente" (Redireciona para WhatsApp).
    - Botão "Subir Documento".
4.  **Resumo da Timeline**: Prévia dos últimos 2 eventos da linha do tempo.

## 📊 Mapeamento de Dados (G5-8)
| Componente | Fonte do Modelo | Descrição |
| :--- | :--- | :--- |
| Saudação | `User.nomeCompleto` | Extraído do objeto de autenticação. |
| Status Card | `Processo.status` | Último processo criado/atualizado. |
| Timeline Preview | `TimelineEvento[]` | Relacionamento 1:N filtrado por `createdAt`. |

## 🕹️ Interações e Regras
- **Pull to Refresh**: Recarrega status e timeline.
- **Clique no Status**: Navega para `CL-05 (Timeline Detalhe)`.
- **Botão WhatsApp**: Abre link externo com template decodificado `processo_id`.

## 🎨 Dicas de Design
- Usar **Grayscale Skeletons** no carregamento inicial.
- O Card de Status deve ser a peça central, usando elevação para destaque.

# Tela: CL-02 - Lista de Processos (Cliente)

- **Tipo**: [Tab Bar] Aba 2
- **Objetivo**: Listar todos os casos vinculados ao CPF do cliente para fácil rastreio.

## 🏗️ Anatomia Visual
1.  **Barra de Busca**: Filtro por nome do processo ou número.
2.  **Filtros Rápidos**: Chips para "Ativos", "Encerrados", "Suspensos".
3.  **Lista (Cards)**:
    - Título do Processo.
    - Número Unificado.
    - Badge de Status (Cor dinâmica por `enum`).
    - Data da última movimentação.

## 📊 Mapeamento de Dados (G5-8)
| Componente | Fonte do Modelo | Descrição |
| :--- | :--- | :--- |
| Lista | `Processo[]` | Array filtrado por `userId`. |
| Badge Status | `Processo.status` | Mapear `EM_ANDAMENTO` -> Azul, `CONCLUIDO` -> Verde. |
| Número | `Processo.numeroUnificado` | Formato XXXX.XXX.XXXX. |

## 🕹️ Interações e Regras
- **Clique no Card**: Navega para `CL-05 (Timeline Detalhe)`.
- **Empty State**: Ilustração amigável se o cliente não tiver processos cadastrados ainda.

## 🎨 Dicas de Design
- Manter espaçamento generoso entre cards para evitar fadiga visual.
- Cores de status baseadas nos tokens de enums definidos no backend.
