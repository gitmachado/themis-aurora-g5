# Tela: CL-03 - Central de Documentos (Cliente)

- **Tipo**: [Tab Bar] Aba 3
- **Objetivo**: Gestão de arquivos enviados e visualização de documentos anexados pelo advogado.

## 🏗️ Anatomia Visual
1.  **Status de Upload**: Header flutuante que aparece apenas durante envios ativos.
2.  **Seções**:
    - "Meus Envios": Fotos de docs, petições enviadas.
    - "Recebidos do Escritório": PDFs de decisões, guias de pagamento.
3.  **Botão flutuante (FAB)**: Ícone de câmera/plus para iniciar upload.

## 📊 Mapeamento de Dados (G5-8)
| Componente | Fonte do Modelo | Descrição |
| :--- | :--- | :--- |
| Lista de Arquivos | `Documento[]` | Relacionado ao `user` ou `processo`. |
| Tipo de Arquivo | `Documento.mimeType` | Ícone muda por extensão (PDF vs Imagem). |
| Data | `Documento.createdAt` | Ordenação descendente. |

## 🕹️ Interações e Regras
- **Clique no Arquivo**: Abre viewer nativo ou download.
- **Upload**: Abre seletor de galeria/arquivos. Limite de 10MB definido na modelagem.

## 🎨 Dicas de Design
- Usar thumbnails para imagens e placeholders coloridos para PDFs.
- Feedback de "Upload concluído" com um check verde persistente por 2 segundos.

# Tela: CL-04 - Chat Espelhado (Cliente)

- **Tipo**: [Tab Bar] Aba 4
- **Objetivo**: Fornecer transparência ao cliente sobre o que foi conversado com a IA/Advogado no WhatsApp.

## 🏗️ Anatomia Visual
1.  **Indicador Canal**: Badge "Conversa via WhatsApp".
2.  **Bolhas de Chat**: Estilo tradicional (Direita: Usuário, Esquerda: Bot/Advogado).
3.  **Aviso de Somente Leitura**: Banner no rodapé informando que o chat interativo é apenas no WhatsApp.

## 📊 Mapeamento de Dados (G5-8)
| Componente | Fonte do Modelo | Descrição |
| :--- | :--- | :--- |
| Bolhas de Texto | `Mensagem[]` | Histórico sincronizado do WhatsApp. |
| Metadados | `Mensagem.origem` | Diferenciar se foi `BOT` ou `HUMANO` (Advogado). |

## 🕹️ Interações e Regras
- **Sincronização**: Atualização em tempo real via Socket ou Long Polling (Latência < 2s).
- **Busca**: Campo de pesquisa por texto dentro da conversa.

## 🎨 Dicas de Design
- Diferenciar visualmente mensagens enviadas pela IA de mensagens enviadas por um Advogado (ex: borda de cor diferente).
